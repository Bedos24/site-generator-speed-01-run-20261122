A faster drop-in for makefun-site 1.0.0 that answers exactly as it does on every case, in less CPU time. `solve.js` re-implements the reference generator's front matter, Markdown subset, template dialect, slug rule and report from scratch — byte-identical output, about 2.4x less CPU on the practice set — and `main.ts` is the harness driver that reads `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
